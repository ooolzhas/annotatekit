Visual feedback for iOS apps, straight to your coding agent.

AnnotateKit turns drawings and comments inside your iOS apps into prompts for your agent. Tap, draw, and send to Claude, Codex, Cursor, or any AI agent. Works with SwiftUI, UIKit, React Native and Expo.

Set up AnnotateKit from github.com/ooolzhas/annotatekit in this app.

Paste this into your agent. Or install by hand →

How to use

  1. Tap Annotate to enable
  2. Draw, tap or hold to annotate
  3. Add a note, attach an image
  4. Tap ↑ to send to your agent
  5. Track status via the inline indicator

Works on device and in the simulator. Everything is hidden behind an #if DEBUG flag.

What agents get

Agents find things by looking, so every note arrives as a specific component to check, not a description to interpret.

  • Lightweight screenshots to eliminate back-and-forth
  • Drawings to easily communicate ideas
  • Coordinates & component trees to edit with surgical precision
  • Device metadata to understand layouts
  • Your notes to bind it all together

Before

You write "blue button near the bottom is too small" and the agent guesses.

After

The agent reads Button "Get started" at (24, 300, 120×44) and can edit the component directly, with zero ambiguity and no extra prompts.
