How it works

AnnotateKit runs inside your DEBUG build, so it reads the real view and accessibility tree. There's nothing to tag, and nothing to copy and paste.

Annotate

Tap the Annotate pill and the screen freezes. Draw around anything, tap an element to select it, or hold to pin an exact spot. Say what should change.

Send

Hit ↑. Every screen you marked goes out as one bundle: 1x screenshots where pixel equals point, crops, coordinates, nearby text and a ready-to-run prompt.

Watch it land

Your agent picks it up, makes the change and reports each note back. The device narrates every step and checks off each note as it's done.

Built for the loop with your agent

Feedback that's precise enough to act on, and a channel back so you know what happened.

Exact coordinates

Every note has a frame, an anchor and the labels around it, in the same points your code uses. Agents grep their way to the right view.

Any agent

Pushed into Claude Code the moment you hit Send. Cursor, Codex, VS Code and any MCP client get it through annotation_wait.

Questions both ways

Pick Fix or Question per note. When something's unclear, the agent asks, and you answer on the phone.

From a real iPhone

Annotate on your phone with no setup in the app. Sends travel over the same developer connection Xcode uses.

Stays out of your way

The launcher keeps clear of your tab bar and toolbars. Nothing heavy runs until you annotate.

Zero cost in Release

Every overlay type sits behind #if DEBUG. Release builds get empty stubs, and the package has no dependencies.

Install

Let your agent set it up, or add it by hand in a couple of minutes.

With Claude Code

The plugin brings the setup skill, the MCP server and the CLI. Then ask Claude to set it up.

/plugin install annotate --marketplace ooolzhas/annotatekit
> Set up AnnotateKit in this app.

By hand

Add the Swift package ooolzhas/annotatekit, then install it at launch and get the CLI.

import AnnotateKit init() { Annotate.install() // DEBUG only }
brew install ooolzhas/tap/annotate

Then connect your agent: channels push Sends into Claude Code, /annotate-watch works without flags, and every other MCP client uses annotate mcp. All the details are in the README.
