Install

Let your agent do it

Paste this into Claude, Cursor or Codex:

Set up AnnotateKit from github.com/ooolzhas/annotatekit in this app.

The agent follows the repo's annotate-setup skill and handles any project: Xcode, XcodeGen, Tuist, SwiftPM, React Native or Expo.

Claude plugin

Skill, MCP server and CLI in one install:

/plugin install annotate --marketplace ooolzhas/annotatekit

By hand

1. Add the package

Link AnnotateKit to your app target with Swift Package Manager (iOS 17+).

https://github.com/ooolzhas/annotatekit

2. Install it at launch

import AnnotateKit

@main
struct MyApp: App {
    init() {
        Annotate.install()   // DEBUG-only; a no-op in Release
    }
    var body: some Scene { WindowGroup { ContentView() } }
}

3. Ignore the bundles

Add .annotate/ to your .gitignore.

4. Install the CLI

Pick one. Skip this with the Claude plugin.

brew install ooolzhas/tap/annotate
npm install -g annotate-ios
mint install ooolzhas/annotatekit

React Native and Expo

iOS only. The npm package carries the pod, and autolinking picks it up. The app's deployment target must be iOS 17 or later.

npm install -D annotate-ios

Expo

Add the config plugin, then run a development build with npx expo run:ios. Expo Go can't load native code.

{ "expo": { "plugins": ["annotate-ios"] } }

Bare React Native

Add two lines to ios/<App>/AppDelegate.swift, then run pod install in ios/.

import AnnotateKit   // at the top

Annotate.install()   // first line of didFinishLaunchingWithOptions

Then ignore .annotate/ and install the CLI as above.
